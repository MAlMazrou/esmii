# Generated input checklist

No value below is selected or generated by Prompt 04. Record each value in the signed activation manifest or the named root-only file; never substitute caller environment variables.

## Non-secret signed manifest values

- deployment epoch, monotonic sequence, release/predecessor IDs and manifest digest
- infrastructure source SHA and immutable shared payload digest
- environment-neutral application payload, web image, and server image digests
- staging application domain, administrator health CIDRs, edge subnet, and exact Caddy IP
- certificate contact
- production application/mail/bounce domains, restricted tester/VPN CIDRs, edge subnet/Caddy IP, mail-admin subnet/Stalwart admin IP, edge mode, and mail mode
- expected rendered Compose, shared configuration, edge fragment, pre-activation CI evidence, schema transition, and production source-checkpoint digests
- opaque sealed-input record IDs and root-keyed MACs

## Root-only secret files — staging

- `postgres-bootstrap-password`, `postgres-migration-password`, `postgres-api-password`, `postgres-worker-password`
- `database-migration-url`, `database-api-url`, `database-worker-url`
- `valkey-users.acl`, `valkey-health-password`, `valkey-api-url`, `valkey-worker-url`
- `operations-health-token`, `better-auth-secret`, `action-link-derivation-keyring`, `tester-allowlist`
- the separate Google client values named by `infra/compose.staging.yaml`

## Root-only secret files — production/later gates

- all independent PostgreSQL, Valkey, health, Better Auth, action-link, and OAuth values named by `infra/compose.production.yaml`
- security-tombstone append-only journal credential
- Stalwart SMTP, webhook, DNS-01, DKIM, and private-administration credentials
- Restic append-only/non-deleting VPS credential and password file
- immutable checkpoint create/list/read credential and curl configuration
- fixed external monitoring/alert credential
- deployment verification public key and separate least-privilege GitHub Deployment-status and GHCR pull credentials

The checklist records names only. Do not place values in Git, manifests, payloads, rendered Compose, logs, browser configuration, or reports.
